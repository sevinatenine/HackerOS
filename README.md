# HackerOS

HackerOS is a WebOS coded in HTML, CSS and JS! It features a few basic apps. It features a desktop environment, file browser, terminal, and basic applications.

HackerOS is powered by a file system library called ZenFS. ZenFS lets you use the same functions in node:fs, but in the web! The FS is stored in IndexedDB. The terminal, file browser and the file picker available for some apps all use the same file system as well.

## Features

- File Browser with drag-and-drop support, file and folder creation, as well as renaming and deletion
- Terminal with basic commands
- Notepad for editing text files with a file picker for saving
- Resizable and movable application windows
- Custom alerts, prompts and a file location picker
- Persistent file system

This project was fully made by me and is open source.

## Try it

You can test the OS by going to the [demo link](https://hacker-os.netlify.app) or download the files, run a localhost web server and open `index.html`.
